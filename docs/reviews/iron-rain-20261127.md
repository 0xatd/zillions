## Scope

Implements Alex's six approved rules for the existing standalone build/defend/conquer maps. Iron Rain is the chosen scenario-style name. The overworld stays disabled and preserved. Existing map geography, IDs and seeds are unchanged. No merge or deployment.

## Changes and existing mechanics retained

- Physical economy: existing building income retained; captured ground now needs a living Forward Camp for periodic resource income. Upgrading improves income; destruction removes it.
- Preparation: 45/30/20 seconds for later maps on Casual/Normal/Brutal, after founding. Greenfall retains the free opening decision and 15/10/7-second first-muster warning. Existing field enemies can still fight; this is a reinforcement pause, not invulnerability.
- Spending: existing economy, camp, defense, upgrade and repair choices retained. Automatic camp production remains, with army orders and hero control.
- Fortification: existing collision, gates, troop egress and generated terrain retained and covered by the established playthrough/exit gates.
- Reinforcement sources: only live, on-map bases muster. Iron Rain no longer stages new waves at captured flags. Razing a base does not increase Threat. The final commander deploys from the last living base when it is attacked; no final wave is generated from ruins.
- Victory: destroy active bases and commander while protecting the Keep. The commander can still use its authored summon ability while alive; existing troops are not erased by destroying their source.
- Presentation: Iron Rain browser filter, map labels and setup title; preparation countdown; objective/tutorial/result wording reflects the new rules.
- Compatibility: snapshot 16 retains prep/release state and loads legacy saves without opting them into new rules. Protocol 29 separates stale peers. Iron Rain state is hashed.
- Regression repair: real map replay exposed a negative completed revive timer versus restored zero. The live timer now clamps at zero. No assertions were relaxed.
