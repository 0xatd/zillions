# CC0 audio

These files are the runtime music, ambience, and sound effects loaded by
`src/soundscape.js`. Every source below is CC0. Procedural Web Audio remains
the fallback when a file fails to load. Hero barks in `click-pack/` are a
separate, older pack and are not part of this set.

Files were trimmed, loop-crossfaded, and re-encoded to Ogg Vorbis so the pack
stays small. The licence is unchanged by that edit.

they loop. Defeat is the Kenney hit jingle played lower.
